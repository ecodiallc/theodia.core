# Theodia Core

## Data Files

| File | Description |
| ---- | ----------- |
| MIB.bible.zip | Marvel Interlinear Bible |
| morphology.sqlite.zip | Morphology database |
| wordsNT.data.zip | New Testament word data |
| wordsOT.data.zip | Old Testament word data |

## Commentaries

`vAIC.commentary.zip` is published in [`theodia.commentaries`](https://github.com/ecodiallc/theodia.commentaries), which is the canonical home for the app's commentaries. This repo carries the data files only.
